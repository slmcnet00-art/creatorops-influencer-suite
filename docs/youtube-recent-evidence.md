# YouTube 검색 적합성과 최근 형식별 조회수

2026-11-04 변경. 검색 결과의 관련 단어 하나와 채널 누적 조회수를 최근 콘텐츠 성과로 취급하던 경로를 보완한다.

## 실제 동작

1. 공식 `search.list`에서 채널·영상 후보를 찾는다. 요리 검색의 추가 검색어는 리뷰·크리에이터 대신 레시피·조리법을 사용한다.
2. `channels.list`에서 공개 국가와 uploads 플레이리스트를 확인한다. 채널 국가가 시청자 국가나 콘텐츠 언어를 증명하는 것은 아니다.
3. 후보별 `playlistItems.list`로 최근 업로드 최대 12개를 읽고, `videos.list`를 최대 50개씩 묶어 공개 제목·설명·조회수·길이·라이브 상태를 조회한다. 영상 다운로드나 비공식 페이지 수집은 하지 않는다.
4. 최근 180일 내 공개 표본을 검증한다. 요리 검색에서는 최소 3개 표본 중 2개 이상, 25% 이상이 관련 콘텐츠여야 한다. 먹방·맛집·쇼핑만 있는 콘텐츠는 제외하며 실제 조리법·재료 설명 근거가 있는 예외는 허용한다. 다른 검색은 최근 표본 3개 이상 중 해당 검색어의 실제 일치 근거 1개 이상을 요구한다. 텍스트 규칙이므로 정밀도·재현율은 실측 평가가 더 필요하다.
5. 관련 영상 원본 링크와 최근 표본 수를 저장한다. 가이드의 근거 링크도 검증한 최근 영상으로 연결한다. 수가 부족하면 무관한 후보로 채우지 않는다.
6. 조회수는 표본 5개 이상이면 상하 20%를 제외한 평균, 그 미만이면 단순 평균과 표본 부족 표시를 사용한다. 라이브는 일반 영상 평균에서 제외하고 0회 조회는 유효한 값으로 취급한다. 조회수 필드가 없는 영상은 0회로 만들지 않는다.

## 형식 판별과 제한

- 180초 초과 일반 영상은 롱폼으로 분리한다. 라이브·라이브 다시보기는 별도 분류한다.
- 180초 이하라는 사실만으로 Shorts를 확정하지 않는다. 썸네일과 임베드 플레이어의 가로세로 비율도 원본 비율로 사용하지 않는다.
- 소유자 권한 등으로 실제 원본 비율을 확인할 수 있는 경우에만 공식 날짜·비율·길이 기준으로 Shorts를 확정한다. 이 조회 경로는 공개 API만 사용하므로 해당 원본 비율이 보통 제공되지 않는다.
- `#shorts` 표시는 **숏폼 추정**이며 확정과 분리해 표본 수·추정 표본 평균만 표시한다. 나머지는 형식 미확인으로 남긴다.
- 확인된 형식별 평균과 추정 Shorts 평균은 별도 필드다. 최근 표본이 있는 YouTube 후보는 확정 표본이 없는 형식의 단가를 전체 평균으로 대신 만들지 않는다. 실제 협의 단가가 있으면 그 금액을 우선한다.
- 과거에 저장한 후보를 새 기준으로 검증했다고 표시하지 않는다. 새 검색 또는 채널 동기화 후 적용된다. 기존 후보나 계약 기록을 삭제하는 일괄 마이그레이션은 없다.

## 호출량·실패·보존

- 동시 채널 업로드 조회는 최대 4개, 검색당 검증 채널은 최소 12·최대 60개로 제한한다. 같은 채널의 업로드 목록을 반복 조회하지 않는다. 영상 상세는 배치 조회한다.
- 국가별 검색의 기존 시간 제한과 검색 페이지 제한을 유지한다. 검증 상한·최근 근거 부족·API 실패로 요청 수보다 적게 반환될 수 있다. 진단에 추가 요청 수와 검증 결과를 남긴다.
- 모든 공식 요청은 기존 사용량 집계를 통과한다. API 키를 로그·진단·클라이언트로 보내지 않는다.
- 새 최근 표본·형식별 평균·관련성 근거도 기존 YouTube API 데이터 30일 갱신·삭제 처리에 포함한다. 180일은 영상 게시일을 고르는 범위이며 데이터를 180일 보관한다는 뜻이 아니다.
- 공개 조회수가 높다는 사실은 광고 전환·매출 성공을 증명하지 않는다. 제목·설명 기반 검증은 영상 장면 전체를 시청하거나 분석한 결과가 아니다.

## 공식 근거

- [3분 Shorts 기준](https://support.google.com/youtube/answer/15424877?hl=en): 2024-10-15 이후 게시, 정사각형 또는 세로 영상, 최대 3분.
- [Videos 리소스](https://developers.google.com/youtube/v3/docs/videos): 공개 길이와 소유자 권한이 필요한 파일 상세를 구분한다.
- [Search.list](https://developers.google.com/youtube/v3/docs/search/list): `videoDuration=short`는 4분 미만 검색 필터이며 Shorts 확정값이 아니다.
