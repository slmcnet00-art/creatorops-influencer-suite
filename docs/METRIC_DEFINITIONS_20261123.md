# 사용자·관리자 지표 정의

2026-11-23 코드 기준. 사용자 대시보드와 관리자 데이터룸은 shared/metricDefinitions.js의 같은 설명을 사용한다.

| 표시 지표 | 실제 계산과 범위 | 확인 사항 |
| --- | --- | --- |
| 후보 구독자·팔로워 합계 | 현재 필터 후보의 followers 합계 | 중복 팔로워를 포함한다. 실제 도달과 구분한다. |
| 후보 예상 조회수 | 현재 필터 후보의 averageViews 합계 | YouTube 최근 180일 최대 12개 영상. 5개 이상이면 상하 20% 제외 평균, 부족하면 단순평균이다. 기간 전체 평균과 구분한다. |
| 조회수 기준 참여율 | 전체 반응 합계 / 전체 조회수 합계 × 100 | 반응 합계가 0이면 제공된 참여율×조회수로 역산하는 기존 계산을 포함한다. 누락 반응의 전체성은 보장하지 않는다. |
| 캠페인 목표 달성률 | 설정된 조회·전환·주문·섭외·매출 KPI별 달성률의 평균 | 각 KPI는 100% 상한, 반올림한다. 목표가 없으면 목표 미설정이다. |
| 실제 매출 | 구매 이벤트 금액 - 환불 이벤트 금액, 하한 0 | 이벤트가 없으면 캠페인 수동 actualRevenue를 사용한다. VAT는 원천 기준 확인이 필요하다. |
| 실제 지출 | 이행 지급액+운영 실제비용 합계와 캠페인 actualSpend 중 큰 값, 하한 0 | 비용 중복, 원가·수수료·VAT 포함 범위는 원천에서 확인한다. |

수집일은 실제 수집 시각이 기록된 필드만 표시한다. 저장·분석 수정 시각으로 대체하지 않는다. 여러 자료가 섞이면 가장 오래된 수집일과 수집일 확인 건수를 표시한다. 출처는 원본의 source, sourceName, metricSources를 사용한다. 출처를 알 수 없는 이전 자료는 확인 필요로 표시한다.

수집값의 빈칸·null·권한 제한과 명시적인 숫자 0을 구분한다. 분모 조회가 없으면 참여율 카드는 계산 불가다. 이전 자료의 0이 원천에서 관측한 0인지 구분할 증거가 없으면 별도 검수해야 한다.

## BRAND DASH 정의 대조 후 확인할 항목

- 참여수 좋아요÷100+댓글은 현재 반응 합계와 다른 별도 지표다. 적용 전 이름·저장단위·공유/저장 포함 범위를 확정한다.
- 나노·마이크로의 동일 1만 경계, MPC 고정 길이와 예시, 월 귀속 주차는 운영팀 확정 후 적용한다.
- 대행 수수료 및 VAT 산식을 합의하기 전 수익성 수식은 현재 코드의 정의로 문서화한다.
- DataFlow·AdFlow의 발급/인증/실수집/갱신은 솔루션별·광고주별·브랜드별로 확인한다. 2026-11-11 검토 결과를 현재 연결 상태로 자동 승계하지 않는다.
- 광고 매체의 ThruPlay·15초 조회·재생 시작, 클릭 정의와 전환 귀속 기간은 서로 다른 원천 지표로 관리한다.

이 변경은 CreatorOps의 사용자 화면·관리자 정의 및 설명에 적용한다. BRAND DASH 원본 기획 엑셀의 승인 전 산식은 별도 확인 항목으로 유지한다.

## 광고주 리포트

리포트 상단은 선택 캠페인의 비용·매출·업로드 콘텐츠로 한정한다. 브랜드 전체 외부 리포트 요약과 혼용하지 않는다. 매출이나 실제 비용 기록이 없으면 연결 필요, 비용이 0이면 효율은 계산 대기로 표시한다. 여러 국가의 캠페인은 국가별 귀속 기록 합계를 사용하며, 국가에 배분되지 않은 캠페인 수동 총액을 배분 완료 금액처럼 표시하지 않는다.

목표 비교는 캠페인 설정의 KPI를 사용한다. 발굴·연락·회신·섭외·업로드는 각 단계의 기록 건수로 표시하며 인원과 콘텐츠 건수를 같은 분모의 퍼널 전환율로 계산하지 않는다. 조회 상위 콘텐츠는 선택 캠페인의 관측된 조회수만으로 순위를 매기며 전환 우수 여부는 별도 검토한다.
