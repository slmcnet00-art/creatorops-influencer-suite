# 캠페인 유형별 섭외 기준 가이드

작성일: 2026-09-09 · 상태: 검토용 제안 / 자동 선발 기준 미적용

## 1. 분류와 적용 범위

- 캠페인 타입: 제안형 / 공개모집 / 앰배서더 / 커머스·제휴 / 공동구매.
- 플랫폼은 YouTube·Instagram·TikTok 등 별도 조건이다. 공동구매를 TikTok 전용으로 제한하지 않는다.
- 커머스·제휴는 제휴 링크·코드 등으로 판매를 유도하고 약정한 성과 보상을 받는 협업을 포함한다. 공동구매는 판매 기간·상품 구성·가격 조건을 정해 진행하는 판매 캠페인이다. 보상에 커미션이 있어도 모든 공동구매가 TikTok Shop Affiliate인 것은 아니다.
- UGC/숏폼은 캠페인 타입에서 삭제한다. UGC 별도 분류는 추가하지 않는다. 기존 저장값은 임의로 다른 타입으로 바꾸거나 캠페인 자체를 삭제하지 않는다. 수정 화면에서 운영자가 새 타입을 선택할 수 있다.
- 콘텐츠 형식은 별도로 다중 선택한다: 숏폼 / 롱폼 / 라이브 / 이미지·캐러셀 / 스토리. `contentFormats` 배열로 저장하며 캠페인 타입과 플랫폼을 바꾸지 않는다. 예: 커머스/제휴 + 숏폼·라이브.
- 기존 형식값이 없으면 미정이며, UGC/숏폼이라는 옛 타입에서 형식을 추정하지 않는다. 생성·수정·조회와 전략·가이드 입력에 선택 형식을 전달한다. AI 프롬프트에도 형식 준수를 명시하지만 플랫폼 지원 여부나 결과물 품질의 자동 검증은 아니다.
- 제안형·공개모집에서도 실제 목표가 판매라면 커머스 또는 공동구매 검증 항목을 추가 적용한다.
- 본 문서는 운영자 검토용이다. 추천 점수·자동 제외·관리자 활성 정책·실제 발송을 변경하거나 승인하지 않는다.

## 2. 모든 캠페인의 공통 필수 확인

| 확인 항목 | 확인 방법 | 미확인 시 처리 |
| --- | --- | --- |
| 국가·언어·상품 배송 가능 지역 | 실제 활동 채널, 제출자료, 캠페인 운영 조건 | 소재 언어와 물류 가능 여부를 확인할 때까지 보류 |
| 카테고리·타깃 적합성 | 관련 최근 콘텐츠와 브랜드 사용 맥락 검토 | 크리에이터 거주 국가만으로 시청자 국가를 단정하지 않음 |
| 실제 운영 계정·연락 권한 | 원본 채널, 본인/대리인 확인, 적법하게 제공된 연락처 | 연락처나 판매자 자격을 추정하여 확정하지 않음 |
| 납기·제작 가능 여부 | 일정과 제출물 합의 | 응답 없음·자료 부족은 미확인으로 분류 |
| 보상·권리 | 제품 제공/제작비/커미션, 사용 기간·매체·지역·편집 범위 합의 | 동의 전 광고 재사용·자동 발송 없음 |
| 투명성·진정성 | 협찬·광고 표시, 실제 사용 및 주장 근거, 이해충돌 확인 | 허위 리뷰·가짜 사용자 위장·성과 조작 요청은 제외 |

공개 수치도 제공 출처의 이용조건을 확인한다. 개인정보는 필요한 범위만 적법하게 처리하고, 제출 실적의 개인 주문정보는 가린다. 법률·광고 표시는 집행 국가와 매체의 최신 기준을 별도 확인한다.

### 자료의 상태를 구분하기

- **검증됨:** 승인된 연결 또는 본인/브랜드가 제공한 증빙과 대조 완료. 출처·기간·단위·확인일 기록.
- **자기 신고:** 크리에이터가 작성했으나 증빙 대조 전. 검증된 숫자와 섞지 않음.
- **추정:** 공개 정보 등을 통한 추정. 실제 시청자 구성·판매액처럼 표시하지 않음.
- **미확인:** 자료가 없거나 API 미제공. 0점 또는 판매 불가로 자동 판정하지 않음.

## 3. 유형별 섭외 기준

| 캠페인 타입 | 가장 먼저 볼 것 | 반드시 받을 증빙·합의 | 성과 판단 | 자료가 부족한 경우 |
| --- | --- | --- | --- | --- |
| 제안형 | 브랜드·제품과 콘텐츠의 적합성, 전달력, 협업 가능성 | 관련 콘텐츠 원본, 견적·일정·제출물 | 목표에 맞는 도달·반응·클릭, 납기·메시지 전달 | 소규모 협업 후 확대 여부 검토 |
| 공개모집 | 모집 요건 충족, 실제 사용 가능성, 지원 내용의 구체성 | 운영 국가·계정·일정·수령 가능 여부, 콘텐츠 샘플 | 적격 지원 비율·완료율·품질·응대 비용 | 모집 요건을 명시하고 수동 심사; 지원 순서만으로 선발하지 않음 |
| 앰배서더 | 장기간의 브랜드 적합성, 신뢰도, 지속 제작·소통 능력 | 여러 시점의 콘텐츠, 협업 이력, 경쟁 브랜드 관계, 활동 기간·권리 조건 | 지속 이행·콘텐츠 품질·반복 반응·관계 유지 | 단기 시험 협업 후 장기 계약 판단 |
| 커머스/제휴 | 실제 판매 참여 자격, 상품·구매층 적합성, 검증된 전환 | 제휴 가능 계정·국가, 판매/클릭 자료와 기간, 커미션·귀속·취소 조건 | 취소·환불 반영 순매출, 확정 주문, 수익 기여 | 무실적 후보는 미검증으로 표시하고 제한된 시험 운영 검토 |
| 공동구매 | 구매층 신뢰, 유사 상품 판매 이력, 기간 한정 판매 운영 능력 | 판매 실적, 가격·기간·재고·배송·CS·환불·정산 역할 | 확정 주문·순매출·기여이익·취소/반품·CS | 경험이 없으면 기존 판매자로 확정하지 말고 작은 물량으로 검증 여부 검토 |

### 제안형: 우리가 먼저 연락하는 협업

1. 제품과 자연스럽게 연결되는 콘텐츠가 있는지 확인한다.
2. 최근 관련 콘텐츠를 복수로 검토하고, 유명한 영상 한 개로 평소 성과를 판단하지 않는다.
3. 조회·참여 수치를 비교할 때 플랫폼·형식·기간·정의가 같은지 확인한다. 정책상 허용되는 지표만 사용한다.
4. 브랜드 톤, 제작 가능 일정, 요청 범위와 견적을 확인한다.
5. B급 제안은 내부 확정 예산 가이드를 기준으로 협의한다. A/S급은 상대의 패키지·희망 조건을 받아 검토한다. 내부 등급은 외부 제목에 노출하지 않는다.

### 공개모집: 참여할 사람이 지원하는 협업

1. 모집 전에 국가·언어·상품 사용 조건·제출물·일정·보상·선발 수를 공지한다.
2. 지원자가 실제 사용자/적합한 제작자인지와 계획의 구체성을 확인한다.
3. 필수 요건 통과 후 콘텐츠 적합성 → 제작 완성도 → 일정·소통 순으로 비교한다.
4. 공개모집이라는 캠페인 분류가 있다고 외부 모집 페이지·접수·자동 심사가 구현된 것으로 보지 않는다.

### 앰배서더: 반복 협업하는 브랜드 파트너

1. 일회성 조회수보다 여러 시점의 콘텐츠 일관성과 브랜드 관계를 본다.
2. 경쟁 브랜드 협업·독점 여부·사용권·일정은 추측하지 말고 계약으로 확인한다.
3. 시험 협업의 납기·수정 대응·메시지 전달 결과를 장기 계약 판단에 활용한다.

### 커머스/제휴: 지속적인 판매 소개와 성과 보상

1. 실제 판매에 사용할 제휴 프로그램과 운영 국가를 먼저 정한다.
2. TikTok Shop인 경우 해당 국가에서 활동 가능한 Affiliate Creator인지 증빙 또는 승인된 연동으로 확인한다. 일반 TikTok 계정이나 높은 조회수만으로 자격을 인정하지 않는다.
3. 판매 기간·상품·가격·순매출·주문·취소/환불을 함께 보고, 가능하면 본인 또는 브랜드의 승인된 자료로 대조한다.
4. 커미션율, 귀속 기간, 중복 주문 처리, 확정 시점, 정산 담당을 합의한다.
5. 우리 코드에 TikTok Shop 모집·주문·자동 커미션 연결이 완료되었다고 표시하지 않는다.

TikTok Shop 공식 안내는 Open Collaboration(공개 협업)과 Target Collaboration(지정 협업)을 구분한다. 이는 CreatorOps의 일반 캠페인 타입을 선택하면 자동 연결되는 기능이 아니다.

공식 참고: https://business.tiktokshop.com/us/affiliate (2026-09-09 확인, 미국 안내; 국가별 조건 별도 확인)

### 공동구매: 기간·가격·운영 조건을 정한 판매

1. 과거 유사 카테고리·가격대의 공동구매 경험과 구매 문의 대응을 확인한다.
2. 조회수와 참여율은 보조 지표다. 판매 내역이 없으면 판매 실적 보유자로 분류하지 않는다.
3. 공급가·판매가·커미션·재고·배송·취소/환불·CS·정산 역할을 확정한다.
4. 목표 매출만으로 진행하지 않는다. 브랜드가 제공한 실제 원가·수수료·물류비·반품 부담·보상액을 기준으로 수익성을 확인한다. 수치가 없으면 수익성은 미확인으로 남긴다.
5. 필요한 파트너 수와 물량은 예산·운영 가능 규모를 확인한 뒤 정한다. 모든 캠페인에 고정된 대량 모집 수를 적용하지 않는다.

## 4. 검토 순서와 승인

1. 캠페인 목표·국가·플랫폼·예산·보상·제출물을 정한다.
2. 공통 필수 요건을 확인한다.
3. 위 표에서 해당 타입의 핵심 증빙을 요청한다.
4. 검증된 사실과 미확인 내용을 분리해 기록한다.
5. 운영자가 적합성·증빙·예산·권리를 검토해 아래 중 하나를 결정한다.
   - **GO:** 조건 확인 및 사람 승인 완료 후 집행 절차로 이동.
   - **MODIFY:** 보상·범위·일정 등 재협의.
   - **HOLD:** 자료·권리·수익성 확인 전 보류.
   - **STOP:** 명백한 부적합 또는 허위 증빙·위장 광고 등 확인.
6. 계약·제안 내용 최종 검토 후 사람이 발송을 승인한다. 가이드 작성만으로 자동 발송하지 않는다.

## 5. 수치 기준은 캠페인마다 설정

- 평균 조회수 5만·참여율 4% 같은 고정선을 모든 타입에 일괄 적용하지 않는다. 특히 공동구매의 판매·운영 역량을 대변하지 못한다.
- 크리에이터 소유/동의 기반 성과, 공개 지표, 자체 캠페인 실적을 출처별로 구분한다. 외부 API 약관이 제한하는 점수 산출이나 재가공을 새로 도입하지 않는다.
- 초기 운영은 일괄 점수 대신 **필수 확인 → 증빙 검토 → 조건 협의 → 사람 승인**으로 진행하고, 실제 운영 결과를 확보한 후 캠페인별 기준을 조정한다.

## 6. 이번 PR 적용 / 미적용

**적용:** 캠페인 타입 이름 변경, UGC/숏폼 옵션 삭제, 콘텐츠 형식 다중 선택·저장·조회·생성 입력 전달, 기존 값 보존·호환, 공동구매 전략의 선택 플랫폼 유지, 텍스트에서 공동구매 캠페인 분류 수정, 회귀 테스트, 본 가이드.

**미적용:** 이 가이드의 자동 점수화·화면 내 가이드 패널·관리자 활성 지침 등록, TikTok Shop API 연동, 기존 ‘틱톡 셀러’ 후보 집계와 레거시 플랫폼 옵션의 전면 개편. 가이드 내용이 이미 자동 추천에 적용되었다고 표시하지 않는다.

운영 배포와 PR 병합은 대표 검토 후 별도로 진행한다.
