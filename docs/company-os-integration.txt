판단 메모리 (2026-10-27)
관리자 > LLM Ops > 피드백 · 판단 사례 · 운영 원칙에서 관리한다.
일반화된 피드백 / 판단 이유·결과 / 원칙 후보를 함께 저장하고 별도 승인한다.
원칙은 해당 워크스페이스 전체 브랜드에 공통이며 기능별로만 적용한다. 브랜드 전용 전략, 개인정보, 원본 메시지, YouTube 통계는 입력하지 않는다.
승인 전·반려·중지 사례는 모델에 전달하지 않는다. 관리자 정책·법적 의무·현재 캠페인 브리프를 우선한다.
다음 전략·추천·가이드·섭외 문구 서버 AI 호출에서 승인 원칙을 참고하며, 이미 생성된 결과나 발송 내용은 변경하지 않는다. 외부 회사 OS의 자체 모델 실행이나 정적 템플릿에는 자동 주입되지 않는다.
LLM 호출 상세의 decisionMemory에는 revision, rules[{caseId,version}]가 남는다. 실제 전달한 원칙은 암호화 입력에 저장되고 기존 30일 보존 정책을 따른다.
실패 재시도는 당시 입력·원칙을 유지한다. 최신 원칙을 다시 붙이지 않는다.
잘못된 원칙은 중지한다. 수정은 새 사례로 제안하고 기존 원칙을 중지한 뒤 새 원칙을 승인한다. 이전 원칙 재승인으로 되돌릴 수 있다. 같은 기능·주제의 중복 승인은 거부한다.
누적 사례는 workspaces.settings.decisionMemoryVault에 AES-256-GCM으로 암호화한다. 기존 LLM_OPS_ENCRYPTION_KEY 보존이 필요하다. 일반 회원에게 원문을 노출하지 않는다. 사례 200개, 기능별 승인 20개, 사례별 검토 이력 100개 한도 초과는 명시적으로 거부한다.
이는 모델 가중치 재학습이나 자동 성과 개선 판정이 아니다. 판단 결과는 관리자가 입력·검토한다.

관리자 API (기존 Owner/Admin Bearer 인증만 허용, OS 서비스 키 불가)
GET /admin/decision-memory -> {data:{revision,cases}}
POST /admin/decision-memory -> {revision,featureKey,topic,feedback,judgment,principle,runId?}; 201 {data:{revision,cases}}
featureKey: campaign-strategy | creator-recommendation | content-guide | outreach-message
POST /admin/decision-memory/:id/review -> {revision,action:approve|reject|retire}; 200 {data:{revision,cases}}
오래된 revision은 409. 잘못된 입력/호출 연결은 400. 호출 연결은 같은 워크스페이스·기능만 허용. 수정 후 새 revision으로 다음 작업을 보낸다.

국가별 자동 번역 YouTube 발굴 (2026-11-03)
- 발굴 화면에서 YouTube 검색 국가를 최대 6개 선택. 단일 선택도 동일한 자동 번역 흐름. 국가별 언어와 실제 검색어/요청·반환 수/캐시·실패·부족 상태 표시.
- POST /discovery/youtube/search {"query":"클렌징밤 리뷰","countries":["KR","JP","US"],"maxResults":15,"strictCountry":true}
- maxResults는 국가별 수가 아닌 총 상한. 나머지는 선택 순서대로 배분. 선택 국가 수보다 작은 수는 400. 기존 country 요청은 기존 응답/동작 유지.
- 지원: KR/CA/US/JP/CN/GB/VN/TH/ID/PH/SG/MY/TW/FR/DE/ES. SEA/EU/ALL은 번역할 언어가 하나가 아니므로 다중 모드에서는 개별 국가로 선택. PH/SG는 영어, MY는 말레이어가 기본 검색 언어이며 모든 현지 언어를 포함하지 않음. 중국/대만은 YouTube API에서 접근 가능한 공개 채널만; 현지 플랫폼 검색 아님.
- 국가별 번역은 단일 AI 호출로 처리하고 LLM Ops(discovery-translation, v1)에 암호화 기록. 동일 원문·국가 조합 번역 캐시 12시간, 동시에 동일한 요청은 공유. 번역 실패·언어/형식 오류 시 원문 검색이나 데모 데이터로 위장하지 않고 오류 반환. 번역은 자동 추정이므로 화면의 검색어 확인 권장.
- 국가별 최대 2개 작업 동시 실행, 국가당 최대 8회 YouTube 검색 페이지·25초(각 외부 호출 최대12초) 예산. 모델 요청 최대20초. UI API 타임아웃120초. 전체 국가가 실패하면 502, 일부 실패는 성공 결과와 국가별 실패 상태 반환. 대상 수가 많아도 결과 수 보장 없음.
- 기본 strictCountry=true: 공개 채널 국가 불일치/미공개 제외. false는 국가 미공개 후보만 검증 대기로 허용. 공개 국가 불일치는 항상 제외. 채널 국가가 시청자 국가/거주지/구매력을 증명하지 않음.
- 번역된 핵심 키워드 모두가 실제 한 영상의 제목/설명에 있어야 후보 채택. 검토 가능한 제한된 동의어(반려견/강아지, セラム/美容液 등)만 허용. 관련 없는 영상 여러 개의 단어를 합쳐 통과시키지 않음. 연결하는 원본은 실제 통과한 근거 영상.
- 상세 화면에 번역 검색어/국가 확인 상태/일치 근거/영상 원본 링크 제공. 검색어 일치는 협업 적합성·섭외 성공률·정확도 %가 아니며 최종 섭외 전 콘텐츠 품질·브랜드/판매자 여부 등 수동 검토 필요.
- 중복 채널은 한 번 저장하고 matchedMarkets로 출처 국가 유지. 실제 검색 실패/부족 시 데모 후보 자동 대체 제거. 다중 검색에서도 기존 서버 API 사용량 집계·경고 적용. 번역 모델 사용량은 YouTube 할당량과 별개.
- 신규 저장한 영상 제목/설명/검색 근거·공개 국가 검증도 기존 YouTube API 30일 미갱신 삭제에 포함. 외부 일괄 내보내기 제한 유지.
- YouTube와 Instagram/TikTok 모두 countries를 지원. Instagram/TikTok의 국가 근거는 아래 공개 검색 정책을 따른다.
원문의 반려견/반려묘·민감성·세럼·바닐라코 같은 등록된 핵심 개념은 번역 누락 시 현지 키워드로 복원하고, 근거 영상에서도 원문 개념을 다시 검증한다. 미등록 고유명사·뉘앙스는 자동 번역의 한계가 있으므로 검색어/근거 검토가 필요하다.


Instagram/TikTok 국가별 자동 번역 발굴 (2026-11-04)
- POST /discovery/google-profiles/search {"query":"뷰티","platform":"Instagram","countries":["KR","JP","US"],"maxResults":9,"strictCountry":false}
- countries 최대6개, 기존 country 단일 경로 보존. 플랫폼은 Instagram/TikTok/all. 총 maxResults를 국가별 배분하고 all이면 두 플랫폼으로 다시 배분. all은 국가당 최소2명, 화면의 전체 플랫폼(YouTube 포함)은 국가당 최소3명 요청.
- 세 플랫폼이 번역 캐시와 LLM Ops(discovery-translation/v2)를 공유. 원문에 없는 등록된 제품 개념을 추가한 번역은 거부. 용어집은 원문에 해당 제품이 있을 때만 제공.
- 공개 검색은 Brave를 우선 사용하고 키가 없으면 기존 Google CSE 설정을 사용한다. 한 국가·플랫폼당 최대2개 검색어, 한 페이지20개(Brave)/10개(CSE)씩. 현지어 크리에이터 키워드를 붙이고 실제 프로필·틱톡 영상에서 확인한 계정 URL만 채택. 관련 없는 레퍼런스 후보로 보충하지 않음.
- Brave 요청은 프로세스 내 대기열로 최소1.1초 간격. 국가당45초/외부요청12초, 국가 병렬도2. 실패한 공급자/플랫폼은 정상 빈 결과로 숨기지 않으며 일부 성공은 보존한다. 실패를 포함한 결과는 정상 캐시에 저장하지 않는다. 브라우저 타임아웃180초.
- Brave country 미지원 범위(TH/VN/SG)는 ALL로 요청하되 현지어 검색어와 국가 텍스트를 검색어에 유지한다. ID는 지원하지 않는 search_lang을 보내지 않는다. 일본어 jp, 중국어 zh-hans/zh-hant 적용. 검색 지역은 계정 국가를 증명하지 않는다.
- 국가 근거는 프로필/검색 텍스트의 국가·도시·국기 표기로 추정한다. 검색 국가, 핸들, 언어만으로 국가를 채우지 않는다. 여러 국가가 언급되면 미확인으로 보존. strictCountry=false 기본: 미확인 포함, 추정 불일치는 제외. true: 해당 국가 추정 근거가 있는 후보만. countryConfidence=detected/unverified, 공식 검증(official)으로 올리지 않음.
- 원문 핵심 조건/번역 검색어가 공개 프로필·콘텐츠 텍스트에서 일치하는 후보만 표시. 명백한 상점·클리닉·플랫폼 계정과 기본 숫자형 TikTok 계정 등을 제외하지만 계정 유형·협업 적합성은 최종 검토 필요.
- 계정 중복 제거 후 matchedMarkets에 검색된 국가를 보존. country 미확인은 미확인으로 유지하며 검색 국가로 덮어쓰지 않는다. 화면은 국가별 언어/검색어/결과 수/국가 추정·미확인/부분 실패·캐시 표시, 근거 원본 링크 제공.
- 공개 검색 썸네일은 만료/차단될 수 있어 신규 후보는 중립 기본 아이콘으로 표시. 임의 인물 사진을 실제 프로필 사진처럼 사용하지 않음. 공식 인증/팔로워 최신성/최근 조회/시청자 국가를 보장하지 않는다.
- 회사 OS에서도 동일 countries 계약 사용. YouTube 한도 사용량은 Google YouTube 호출만 집계하고 Brave/CSE·번역 모델 요금은 별도다.
- 공급자 문서: https://api-dashboard.search.brave.com/api-reference/web/search/get 및 https://api-dashboard.search.brave.com/documentation/guides/rate-limiting

캐나다(CA)도 세 플랫폼의 국가 선택·자동 번역 검색을 지원하며 기본 검색 언어는 영어다. 다언어 국가의 모든 언어를 자동으로 포함하지 않으므로 화면에 국가별 기본 언어를 표시한다. 국가 목록은 초기 운영 프리셋이며 API 지원 전체 국가 목록을 뜻하지 않는다.
