# YouTube 심사 후속 개선

## 이번 PR

- 영문 심사 모드, 심사용 데모, 국내 화면에서 YouTube 사용자 수를 `Subscribers`로 통일한다.
- 발굴 상세, 추천 상세, 목록, 출처 지표, 후보 그룹, 레퍼런스, 메시지 등 플랫폼을 알 수 있는 표시 영역에 공통 함수를 사용한다.
- 다른 플랫폼은 팔로워 표기를 유지하며 혼합 집계는 두 용어를 병기한다.
- 데모 URL 입력, 발굴 검색, 콘텐츠 레퍼런스 검색에 읽기 전용 입력 사용 및 일괄 내보내기 제한 안내를 표시한다. 영문 심사 모드에는 영문 안내를 직접 제공한다.
- 저장된 `followers` 필드와 기존 DB 구조는 변경하지 않는다.

## 기본 브랜치에 이미 포함된 개선

이번 PR은 다음 기능을 새로 구현한 것으로 주장하지 않는다.

- YouTube 선택 시 발굴 내보내기 버튼 숨김 및 검색 결과 내보내기에서 YouTube 제외 (`src/App.jsx`).
- 공개 YouTube API 데이터 30일 경과 시 정리 (`server/youtubeRetention.js`, `tests/youtube-retention.test.mjs`).
- 이용약관·개인정보처리방침 및 심사 페이지 데이터 관리 안내.

## 검증 및 제출 조건

- `npm test`: 44개 통과.
- `npm run build`: 성공. 기존 500KB 초과 번들 경고는 남아 있음.
- `npm run lint`: 통과. 대용량 App.jsx 관련 Babel 안내만 출력.
- `node scripts/test-youtube-compliance-ui.mjs`: 로컬 미리보기에서 합성 API 응답으로 데모·영문·국내 표시, 타 플랫폼 표기 유지, 다운로드 버튼 조건 검증.
- 브라우저 테스트는 UI 회귀 검증이며 운영 DB의 보존 작업을 검증한 것은 아니다.
- 이 PR 자체는 운영 배포 또는 심사 승인을 뜻하지 않는다. 대표 검토·병합·배포 후 실제 운영 화면으로 제출 영상을 준비한다.
- PR #3(위닝 소재) 및 #4(캠페인 정리)는 포함하지 않았다. 동일한 App.jsx를 수정하므로 병합 순서에 따라 충돌 확인이 필요하다.
