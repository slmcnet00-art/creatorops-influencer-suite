# 손상된 업로드 문구 대체안

원문 복원이 아니라 새 문구 제안입니다. 승인 전까지 아래 문구를 화면 코드에 적용하지 않았습니다.

| 위치/용도 | 제안 문구 |
|---|---|
| 추적 업로드: 인플루언서 설명 | 업로드한 자료 기준 · 공개 지표 확인 필요 |
| 추적 업로드: 인플루언서 상태 | 확인 필요 |
| 추적 업로드: 기본 카테고리 | 기타 |
| 추적 업로드: 기본 콘텐츠 제목 | 업로드한 콘텐츠 |
| 추적 업로드: 지표가 있는 게시물 상태 | 추적 중 |
| 추적 업로드: 지표가 없는 게시물 상태 | 수치 확인 필요 |
| 추적 업로드: 지표 출처 | 사용자 업로드 자료 |
| 추적 업로드: 활동 기록 | 콘텐츠 URL {등록 수}건 등록 |
| 추적 업로드: 가져오기 현황 | 원본 {행 수}행 보존 · 콘텐츠 {등록 수}건 등록 |
| 추적 업로드: 완료 알림 | 콘텐츠 {등록 수}건을 등록했습니다. 중복·누락 {제외 수}건은 제외했으며 원본 자료는 보존했습니다. |
| 추적 업로드: 오류 | 콘텐츠 자료를 불러오지 못했습니다. 파일 형식을 확인해주세요. |
| 그룹 업로드: 기본 카테고리 | 기타 |
| 그룹 업로드: 기본 설명 | 업로드한 크리에이터 자료 |
| 그룹 업로드: 인플루언서 상태 | 확인 필요 |
| 그룹 업로드: 기본 그룹명 | {브랜드명} · 업로드 그룹 |
| 그룹 업로드: 기본 그룹 유형 | 즐겨찾기 |
| 그룹 업로드: 그룹 설명 | 업로드한 크리에이터 목록으로 만든 그룹입니다. |
| 그룹 업로드: 담당자 | 운영 담당자 |
| 그룹 업로드: 활동 기록 | 크리에이터 {등록 수}명 등록 |
| 그룹 업로드: 가져오기 현황 | 원본 {행 수}행 보존 · 크리에이터 {등록 수}명 등록 |
| 그룹 업로드: 완료 알림 | 크리에이터 {등록 수}명과 그룹 {그룹 수}개를 등록했습니다. 제외 {제외 수}행 · 원본 자료는 보존했습니다. |
| 그룹 업로드: 오류 | 크리에이터 자료를 불러오지 못했습니다. 파일 형식을 확인해주세요. |

원래 21곳 중 상태를 나누는 조건문 1곳은 두 문구로 나누어 제안했습니다.
