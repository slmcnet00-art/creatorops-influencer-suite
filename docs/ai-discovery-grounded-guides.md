# 근거 기반 발굴·전략·가이드 생성

## 발굴과 최종 선정

1. AI가 원문의 제품·국가 조건을 유지해 현지어 검색어와 관련 세부 주제 두 개까지 준비한다.
2. 기존 실제 API/공개 검색을 호출한다. 충분한 결과가 있으면 확장하지 않으며, 국가당 최대 세 검색어만 실행한다. 국가·원문 근거를 재검사하고 실제 프로필 ID로 중복 제거한다. API 권한·할당량 오류는 추가 확장을 중단한다.
3. 캠페인 국가·플랫폼·사용자가 지정한 최소 지표로 후보를 좁힌다. 기존 규칙 점수는 AI 평가 배치(최대 50명)를 준비하는 순서로만 사용한다.
4. 최대 10명씩, 동시 두 배치로 전원을 평가한다. 최종 배정 목표가 10명이어도 평가 대상을 10명으로 줄이지 않는다. AI가 실제 프로필 본문과 최근 관련 영상 제목·설명을 근거 ID와 함께 평가한다. 검색 국가를 실제 계정/시청자 국가로 바꾸지 않는다. 결과에 없는 인물·근거, 중복·누락된 평가, 근거 없는 확정 추천은 거부한다.
5. AI 적합성 점수로 순서를 바꾼 다음 총예산·기집행액·인당 한도·협의 금액 또는 예상 상한으로 최종 배정한다. 미평가·검토 대기·제외 후보와 단가 미확인 후보는 자동 배정하지 않는다. 목표 인원을 억지로 채우지 않는다.

50명 초과 풀은 이번 실행에서 미평가로 남는다. 평가 점수는 모델 판단이며 전환 확률이나 검증된 정확도 수치가 아니다. 검색 확장은 검색 비용·대기 시간을 늘릴 수 있다.

## 관리자 자료가 생성에 도달하는 방식

- 매 생성 시 공유 DB의 활성 관리자 정책을 새로 읽는다. DB 조회에 실패하면 이전 메모리 정책으로 생성하지 않는다.
- 본문이 추출된 첨부만 참고한다. URL·폴더 링크만 있고 본문이 없으면 읽었다고 표시하지 않는다. Drive 원본 변경은 관리자 동기화로 DB에 반영한 후 다음 생성부터 적용된다.
- 최대 60,000자 내에서 자료별 본문을 배분하고, 큰 파일은 요청과 관련된 부분을 발췌한다. 자료 ID·정책 버전·본문 지문·사용 문자 수·제외 사유를 남긴다.
- 브랜드에 남은 데모 학습자료와 신규 브랜드용 기본 제품·플랫폼은 실제 제품 사실로 사용하지 않는다. 현재 캠페인의 제품·플랫폼·형식·예산이 예시보다 우선한다.
- 학습은 생성 시 자료를 참고하는 방식이다. 모델 가중치 재훈련이나 Drive 원본의 실시간 자동 반영을 의미하지 않는다.

## 전략·공통·개별 가이드

- 전략과 가이드 모두 초안 작성 → 출처·기능·크리에이티브 검토의 두 단계로 생성한다. 단계별 호출·모델·사용량을 LLM Ops에 기록한다. 검토 모델 기본값은 `gpt-4.1`, 선택 설정은 `OPENAI_CREATIVE_REVIEW_MODEL`이다. 호출 비용과 시간이 기존 한 단계보다 증가한다. 가격표가 없는 모델은 비용을 임의 계산하지 않는다.
- 서로 다른 세 콘셉트, 첫 3초 화면·대사, 구체적 촬영표, 실제 원본 링크, 단일 변수 비교 테스트를 요구한다. 미확인 기능을 핵심 아이디어의 전제로 만들지 않는다.
- 학습자료 적용에는 실제 본문과 일치하는 원칙 인용과 제안 적용을 요구한다. 모델이 스키마를 실측 분석으로 꾸민 인용은 저장하지 않는다. 인용은 원문 일치를 증명하며 실제 캠페인 효과를 보장하지 않는다.
- 개별 가이드도 관리자 AI API를 호출해 해당 인물의 공개 콘텐츠와 공통 가이드를 함께 읽는다. 최근 일치 영상은 역대 TOP 3나 전체 영상을 시청한 분석으로 표시하지 않는다. 로컬 문구를 이어 붙인 가이드를 AI 생성물로 대신 저장하지 않는다.
- 생성 실패 시 기존 가이드는 유지한다. 검토 단계만 별도 재시도하면 출처 검증을 건너뛸 수 있으므로 관리자 로그의 일반 재시도 대신 캠페인에서 재생성한다.
- 이전 생성물은 자동으로 덮어쓰지 않는다. 재생성한 결과부터 화면의 **학습자료 적용 내역**에서 원문 자료·버전·검토 내용을 확인한다.

검토 모델과 형식 검사도 실제 영상 시청·제품 기능 검증·광고 성과 실험을 대신할 수 없다. 확정 앱 화면, 기능 근거, 설치 링크, 계약 조건이 없으면 제작 승인 전 확인 항목으로 남긴다.
