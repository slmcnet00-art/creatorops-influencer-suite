# 캠페인 견적·컨택·후보 정보

## 캠페인 견적서

캠페인 상세의 **캠페인 견적서**에서 배정 후보를 자동으로 읽습니다. 포함 여부, 수량, 단가, 운영 관리비, 배송비, 기타 비용, 부가세를 조정하고 **견적 초안 저장** 또는 **견적서 Excel 다운로드**를 누릅니다.

- 확정 협의가 → 원본 제안가(KRW) → 내부 계산 추정가 순으로 적용합니다.
- 원본 제안가는 **제안 단가 · 미확정**으로 표시합니다. 견적 초안의 단가 수정은 계약 단가나 집행액을 변경하지 않습니다.
- 미확인 단가는 확인 필요로 남기고 합계에서 제외합니다. 배송·제품·2차 활용 비용은 임의로 만들어 넣지 않습니다.
- 기존 참고자료의 오래된 금액·수신인·일정은 복제하지 않습니다. 항목/수량/단가/비고/소계/부가세/총액 구조를 참고합니다.
- 견적 설정은 `campaign.quoteSettings`에 저장하며, 배정 변경은 다음 견적 계산에 반영됩니다.

## 메시지

메시지의 **캠페인 컨택 메시지**에서 제안 유형·채널·양식 언어와 미리보기 후보를 고릅니다. 제공 컨택 문서의 소개 → 협업 내용 → 일정 → 회신 요청 흐름을 반영하고, 오래된 개인명·브랜드·일정·첨부 약속 및 확인하지 않은 칭찬은 제외했습니다.

`{{creatorName}}`, `{{brand}}`, `{{campaignName}}`, `{{product}}`, `{{deadline}}`, `{{offer}}`, `{{replyRequest}}`, `{{formats}}`, `{{sender}}`가 자동 치환됩니다. 양식은 `campaign.contactTemplates`에 `email:ko`, `dm:en` 같은 키로 저장합니다.

**배정 후보 초안 만들기**는 국가별 발송 언어로 승인 대기 메시지를 생성합니다. 기존 메시지를 덮어쓰거나 발송하지 않으며, 중복 생성하지 않습니다. 한국어 참고본은 해외 발송 본문에 합치지 않습니다. 미정 제품은 일반적인 브랜드 제품으로 표현하고, 확정되지 않은 날짜는 협의로 표시합니다. 발송 전에 운영자가 상세 조건을 확인해야 합니다.

## 즐겨찾기 후보

- 실제 프로필 이미지가 있을 때만 사진을 표시합니다. 이미지 미확인은 이니셜과 확인 필요로 표시합니다.
- 채널 팔로워와 전체 채널 합산 팔로워를 구분합니다. 합산 값을 플랫폼 단독 값으로 복사하지 않습니다.
- 채널별 펼침에서 원본 링크·조회수·국가·언어·수집 시점을 확인합니다. 미수집 참여율을 0%로 표시하지 않습니다.
- 브랜드 DB 저장 시 캠페인의 `creatorIds`, 그룹의 `creatorIds`와 기존 `memberIds`를 모두 보존합니다.
- 실제 고객 리스트·연락처·프로필 이미지 및 DB 작업용 자격증명은 Git에 포함하지 않습니다.
