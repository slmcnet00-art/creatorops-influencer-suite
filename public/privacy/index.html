CreatorOps Influencer Suite Privacy Policy

Last updated: September 3, 2026

CreatorOps Influencer Suite is an influencer campaign management platform operated by Mipingplan.

1. Information We Collect

  • Account information such as name, email address, team, role, and authentication records.
  • Campaign information entered by users, including brand name, product details, campaign brief, target persona, keywords, schedules, KPI targets, creator notes, outreach status, and report data.
  • User-provided search terms and public YouTube channel or video URLs used to request read-only public data.
  • Public YouTube API Data, including channel and video identifiers, titles, descriptions, channel names, publication dates, thumbnails, duration, subscriber counts, view counts, like counts, and comment counts where made available by the YouTube Data API.
  • Technical information such as browser type, device information, essential session data, usage logs, and error logs for security and service improvement.

2. How We Use Information

  • Provide creator discovery, content reference search, campaign management, outreach preparation, and performance reporting.
  • Send user-entered search terms or public URLs to our backend and the YouTube Data API solely to retrieve public, read-only metadata. CreatorOps does not use these inputs to upload, publish, comment on, edit, or delete content on YouTube.
  • Help authorized workspace members evaluate creator and public-content fit for brand campaigns.
  • Generate campaign strategy, outreach messages, content guides, and reports using AI-assisted workflows when the user chooses those features.
  • Maintain security, prevent abuse, debug issues, and improve service reliability.

3. YouTube API Services

CreatorOps Influencer Suite uses YouTube API Services. CreatorOps currently requests public YouTube channel and video metadata using read-only access and does not request access to private YouTube user data or YouTube write permissions.

YouTube API Data is used for creator discovery, content reference search, and campaign performance reporting inside the user's authorized CreatorOps workspace. By using CreatorOps, users agree to be bound by the YouTube Terms of Service. Google's handling of information is described in the Google Privacy Policy.

4. Processing, Sharing, and Service Providers

CreatorOps displays data only to authorized members of the relevant workspace. We do not sell personal information or YouTube API Data. We disclose data only as needed to provide the service, protect the service, comply with law, or follow the user's instruction.

Processors and integration providers may include Render for application hosting, Supabase for database and authentication, Google/YouTube for API requests, Google for connected email features, and OpenAI for user-selected AI-assisted workflows. These providers process only the information needed for their respective service.

5. YouTube API Data Retention and Refresh

Non-Authorized public YouTube API Data and statistics are refreshed or deleted within 30 calendar days. CreatorOps runs a daily refresh process and displays the most current available API Data. If an item cannot be refreshed before the 30-day limit, the API-derived data is removed and is not displayed until it is collected again.

User-provided campaign records, notes, and URLs are kept separately from API-derived statistics and may be retained as operational data until the user deletes them or requests deletion. Raw YouTube API event records and metric snapshots older than 30 days are deleted.

6. Cookies and Similar Technologies

CreatorOps and its service providers may use cookies, browser local storage, or similar technologies that are necessary for authentication sessions, security, saved preferences, and temporary application state. CreatorOps does not use YouTube API Data for advertising cookies or cross-site behavioral tracking.

7. User Control, Revocation, and Deletion

Users may request access, correction, export, or deletion of their account and campaign data. When a Google account is connected through OAuth, users may revoke access at Google Security Permissions. Revocation stops future OAuth access; users may also contact us to request deletion of stored data.

8. Security and Contact

We use reasonable administrative, technical, and organizational safeguards to protect information. However, no internet-based service can guarantee absolute security.

For privacy questions, access or deletion requests, or questions about YouTube API Data, contact mipingplanai@gmail.com.
